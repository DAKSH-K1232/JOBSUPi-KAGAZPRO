# **App Name**: Kagaz Pro

## Core Features:

- Multi-Modal Data Input: Collect user details through voice input, chat-style interface, traditional forms, and image uploads for maximum accessibility. Prioritizing Voice + Forms initially.
- Resume Generation: Generate professional-looking resumes in PDF format, and also create a mobile-friendly web profile for online sharing.
- QR Code Generation: Automatically generate a QR code for each resume, which directly links to the user's web profile for easy sharing.
- Resume Versioning: Enable users to save multiple versions of their resume, and allow the addition of comments or notes for feedback and iterative improvements.
- Skill Inference: Use AI to infer potential skills based on the user's voice input. This is intended to provide suggestions on skills they may want to include, and can be configured with a tool for more reliable identification of skills.

## Style Guidelines:

- Primary color: Indigo (#4B0082) for professionalism and trust.
- Background color: Light gray (#F0F0F0), providing a clean and neutral backdrop.
- Accent color: Teal (#008080) to highlight key elements.
- Body and headline font: 'Inter', a grotesque-style sans-serif font that gives a modern and neutral look to both headings and body text.
- Use clean, professional icons to represent different sections of the resume (e.g., work experience, education, skills).
- Maintain a clean and structured layout with clear section headings and logical flow.
- Subtle animations or transitions for interactive elements (e.g., expanding sections, loading indicators).
