KAGAZPRO is a website for each category of workers. 

On this website Blue collar, grey collar and white collar workers can make and preview their resumes at the same time.

Also, user can switch to hindi language for accessiblity.

I have also added voice option to add skills into the resume.

for exporting the saved resumes, user can generate a QR code, link or download it into pdf form.

This will help people to create resumes on their own in a more accessible way and this project will create ease for community and its people.
